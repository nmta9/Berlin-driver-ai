# Berlin Driver AI

Mobile-first decision support for Berlin ride-hailing drivers.

## Planned features
- Berlin map and driver location
- Traffic-aware routing using TomTom (API key configured outside source control)
- Berlin events, weather, airport and transit signals
- Smart cruising suggestions based on estimated net earnings, compared with staying put

**Note:** No live Uber demand data is available; demand scores are estimates, not verified ride requests.
